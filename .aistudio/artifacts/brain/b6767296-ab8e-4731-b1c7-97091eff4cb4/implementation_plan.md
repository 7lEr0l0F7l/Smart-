# 스마트 온실 홍시 관찰 KIT 모바일 앱 (Hongsi Kit)

스마트 온실 홍시 관찰 KIT와 연동하여 아동·학부모를 위한 친근한 AI 반려 과일 '감감이' 관찰 경험(교육용)과 성인·원예인을 위한 정밀 온·습도·조도 센서 모니터링 및 실시간 카메라 타임랩스(취미용)를 제공하는 모바일 최적화 애플리케이션입니다.

> [!IMPORTANT]
> **사용자 피드백 및 확정된 핵심 설계 사항**
> - **센서 및 카메라 연동**: 실물 아두이노 REST/스트리밍 API 연결과 함께 데모 및 브라우저 테스트를 위한 고정밀 가상 센서 시뮬레이터(환경 조절 다이얼, 가상 카메라 스트림)를 동시 지원합니다.
> - **교육용 AI 감감이**: Gemini API 기반의 반려 과일 챗봇 페르소나를 구축하고, Web Speech API / TTS 음성 낭독 및 4단계 감정 표정 인터랙션(초록감 -> 주황감 -> 홍시 숙성 변화)을 제공합니다.
> - **화면 레이아웃**: 스마트폰 디바이스 프레임 UI(실제 모바일 환경 화면비와 터치 인터랙션, 상단 상태바 및 하단 탭바)를 기본 탑재하고 화면 배율 전환을 지원합니다.

## 1. Overview & Core Concept

- **What It Does**: 스마트 온실 내부에 장착된 아두이노(DHT22 온습도, CdS 조도 센서, ESP32-CAM 또는 USB 웹캠)와 연동하여 홍시의 후숙 과정을 관찰하고 기록합니다. QR코드로 접속한 후 학습 목적에 맞는 모드를 선택하여 이용할 수 있습니다.
- **Target Audience / Persona**:
  1. *어린이 및 학부모 (교육용)*: 딱딱한 수치 대신 반려 과일 '감감이'와 대화하며 자연과학과 과일 후숙의 원리를 배우는 탐구자.
  2. *성인 및 식물 집사 (취미용)*: 정확한 온도·습도·조도 데이터 변화 추이를 모니터링하고 최적의 연시/홍시 환경을 연구하는 홈파밍 연구자.
- **Key Value**: 센서 데이터와 친근한 AI 스토리텔링을 융합하여 과일이 익어가는 시간의 가치를 재미있고 과학적으로 체감하도록 돕습니다.

## 2. User Experience & Visual Design

### 2.1 핵심 사용자 흐름 (User Flows)

```
[QR코드 스캔 / 온보딩]
        │
        ├─► [모드 선택]: [교육용 (감감이와 놀기)] or [취미용 (스마트 온실 관제)]
        │
        ├──► 【교육용 모드】
        │       ├─► 메인: 3D/일러스트 감 캐릭터 '감감이' 실시간 표정 & 숙성도 링
        │       ├─► AI 대화: '감감이'와 실시간 음성/텍스트 챗 (과일의 심리·온습도 상태 피드백)
        │       ├─► 다중 관찰: '우리집 대봉감 1호', '단감 2호' 간편 프로필 전환 (멀티 감 관리)
        │       └─► 퀘스트 & 칭호: "오늘 햇빛 쬐어주기", "온도 체크하기" 미션
        │
        ├──► 【취미용 모드】
        │       ├─► 센서 대시보드: 실시간 온도(°C), 습도(%), 조도(Lux) 실시간 차트 & 통계
        │       ├─► 카메라 뷰어: 실시간 내부 캠 스트림, 타임랩스 재생, 스냅샷 저장
        │       └─► 장치 연동 설정: 아두이노 IP/엔드포인트 설정 + 가상 시뮬레이터 조작
        │
        └──► 【공통 기능】
                ├─► 관찰 일기: 날짜별 사진, 센서 로그 스냅샷, 일기 기록 및 캘린더 뷰
                └─► 커뮤니티: 관찰 공유 갤러리 및 홍시 디저트 레시피 게시판 (댓글/좋아요)
```

### 2.2 비주얼 아이덴티티 & 테마
- **컬러 팔레트**:
  - Dominant Neutral: `#FAFAF9` (Stone-50 온화한 자연 채광 캔버스)
  - Surface Containers: `#FFFFFF` (깔끔한 카드 및 시트)
  - Primary Brand Accent: `#EA580C` / `#C2410C` (잘 익은 홍시 주황 오렌지)
  - Secondary Nature Accent: `#15803D` (건강한 감꼭지와 나뭇잎 딥 그린)
  - Data & Metrics Accent: `#0284C7` (수분 및 정밀 계측 스카이 블루)
- **타이포그래피**:
  - Headings: `Outfit` & `Pretendard / Plus Jakarta Sans` (가독성과 부드러움을 겸비한 볼드 서체)
  - Data & Metrics: `tabular-nums font-mono` (센서 수치 수직 정렬)
- **디바이스 프레임워크**:
  - iOS/Android 스타일의 슬림 베젤 스마트폰 목업 프레임 (390×844px 뷰포트 기준)
  - Dynamic Island/노치 영역, 상단 시계·배터리 인디케이터, 하단 제스처 바
  - 하단 고정 4-탭 내비게이션 바 (홈, 관측실/대화, 관찰일기, 커뮤니티)

## 3. Key Product Decisions & Trade-Offs

| 항목 | 채택된 방식 | 선정 이유 & 대안 비교 |
| :--- | :--- | :--- |
| **장비 연동 아키텍처** | **하이브리드 모드 (실물 아두이노 REST API + 브라우저 가상 센서 엔진)** | 실제 키트가 없거나 개발 중인 환경에서도 온도/습도 슬라이더, 환기팬/LED 스위치, 조도 시뮬레이션을 즉시 시험할 수 있으며, 실제 하드웨어 연결 시 IP 주소 입력만으로 즉각 실데이터 수신 가능. |
| **AI 챗봇 엔진** | **서버 사이드 Gemini API (`gemini-3.8-flash`) + Web Speech TTS** | 감감이의 나이/인격/현재 온실 센서 수치를 컨텍스트로 주입하여 "나 지금 너무 더워! 24도 정도로 맞춰줄래?"와 같은 상황 인지형 감정 대화 실현. |
| **다중 계정 / 다중 감 관리** | **간편 프로필 스위처 (Family Quick-Switch)** | 복잡한 패스워드 재인증 없이 부모/자녀가 원터치로 전환하며 온실 1번(대봉감), 2번(단감)을 개별적으로 기록 가능. |
| **데이터 영속성** | **로컬스토리지 + 인메모리 커뮤니티 시드 데이터베이스** | 별도의 외부 DB 설치 없이도 즉시 일기 작성, 사진 업로드, 레시피 공유 및 댓글 작성이 영구 보존됨. |

### 4.2 주요 데이터 모델

```typescript
// 센서 측정값 모델
interface SensorData {
  timestamp: string;
  temperature: number; // °C (예: 21.5)
  humidity: number;    // % (예: 68.2)
  lux: number;         // Lux (예: 450)
  co2?: number;        // ppm (선택적)
  fanStatus: boolean;  // 온실 환기팬 가동 여부
  ledStatus: boolean;  // 온실 생장 LED 점등 여부
}

// 감 프로필 (다중 감 지원)
interface PersimmonProfile {
  id: string;
  name: string;        // 예: '말랑이', '대봉 1호'
  variety: 'daebong' | 'sweet' | 'bansi'; // 대봉감, 단감, 반시
  startDate: string;
  currentStage: 'green' | 'turning' | 'ripe' | 'hongsi'; // 풋감 -> 주황감 -> 완숙 -> 홍시
  sweetnessBrix: number; // 당도 추정치 (Brix)
  ripeningScore: number; // 0 ~ 100%
  avatarMood: 'happy' | 'thirsty' | 'hot' | 'chilly' | 'sleepy';
}

// 관찰 일기 모델
interface ObservationDiary {
  id: string;
  date: string;
  title: string;
  persimmonId: string;
  stage: string;
  content: string;
  imageUrl: string;
  sensorSnapshot: {
    temp: number;
    humidity: number;
  };
  tags: string[];
}

// 커뮤니티 게시글 모델 (관찰 공유 / 레시피)
interface CommunityPost {
  id: string;
  author: string;
  authorRole: 'child' | 'parent' | 'hobbyist';
  category: 'observation' | 'recipe' | 'qna';
  title: string;
  content: string;
  imageUrl?: string;
  likes: number;
  comments: { id: string; author: string; text: string; date: string }[];
  createdAt: string;
}
```

## 5. Implementation Roadmap (Phases)

1. **Step 1: Core Layout & Mobile Shell System**
   - 스마트폰 디바이스 프레임 UI, 상단 상태바 및 모드 스위처(교육용/취미용).
   - QR코드 온보딩 스캐너 모달 및 첫 실행 시 모드 선택 플로우 구축.
2. **Step 2: 아두이노 센서 & 카메라 연동 엔진**
   - 실시간 가상 센서 엔진(온도/습도/조도 슬라이더, 환기팬/LED 토글 제어) + 실물 아두이노 IP 주소 연동 탭.
   - SVG 라인 차트 기반 온·습도 실시간 그래프 시각화.
   - 내부 카메라 라이브 프리뷰, 타임랩스 시뮬레이터 및 스냅샷 캡처 기능.
3. **Step 3: 교육용 모드 (AI 감감이 챗봇 & 반려 과일)**
   - 감감이 인터랙티브 캐릭터 (눈 깜빡임, 감정 상태 애니메이션).
   - 온실 환경 데이터가 실시간 주입되는 Gemini AI 대화 시스템 (`/api/gemini/gamgami`).
   - Web Speech API 기반의 귀여운 낭독 음성(TTS) 토글.
   - 부모/자녀 간편 계정 및 다중 감 프로필 전환 기능.
4. **Step 4: 공통 기능 (관찰 일기 & 레시피 커뮤니티)**
   - 날짜별 관찰 일기 에디터 및 센서 스냅샷 자동 첨부 기능.
   - 홍시 라떼, 홍시 스무디, 홍시 곶감 샐러드 등 레시피 공유 및 사진 갤러리 피드.
   - 댓글, 좋아요, 검색 및 카테고리 필터링.
